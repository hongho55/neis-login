# 업무 시작 도우미 · 처음 사용하는 선생님께

> 새 설치 방식의 안내 초안입니다. 아직 이 안내에 해당하는 배포 파일은 제공되지 않았습니다.

## 처음 한 번만

1. 전달받은 **업무 시작 도우미 설치 파일**을 엽니다.
2. **설치**를 누릅니다.
3. 설치가 끝나면 **도우미 열기**를 누릅니다.
4. 도우미 안내에 따라 업무포털을 열고 **본인 인증서를 선택한 뒤 암호를 등록**합니다. 암호는 채팅이나 다른 사람에게 보내지 않습니다.

## 다음부터

바탕화면의 **업무 시작 도우미**를 열고 **업무 시작**을 누르면 됩니다.

Windows에 로그인할 때 자동으로 열리게 하려면 도우미의 **자동 시작**을 켭니다. 프로그램만 열어 두고 직접 시작하는 방식과, 바로 로그인하는 방식 중 선택할 수 있습니다.

## 설치가 막히면

게시자·보안제품·학교 정책 안내로 설치가 막히면 그 화면에서 멈추고 배포한 사람이나 학교 전산 담당자에게 문의해 주세요. 보안프로그램을 끄거나 예외를 추가할 필요는 없습니다.

이 도우미는 교육청의 공식 프로그램이 아닌 개인 프로젝트이며, 현재 강원 업무포털과 Windows용 Edge를 대상으로 합니다.
