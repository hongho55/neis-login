# 업데이트 방식

현재 버전은 자동으로 인터넷에서 업데이트하지 않습니다. 설치 프로그램을 새로 받아 실행하는 수동 업데이트 방식입니다.

이번 배포본은 `TeacherWorkStart-Setup-0.4.16.exe`를 실행하면 기존 도우미 종료 여부를 확인하고, 새 실행 파일과 설정 파일의 SHA256을 확인한 뒤 설치합니다. 기존 설정·Windows 자격 증명·자동 시작 설정은 보존하며 설치 완료 후 사용자가 직접 도우미 열기를 눌러 시작합니다.

자동 업데이트를 추가하려면 GitHub Releases 같은 고정 배포처에 버전 매니페스트와 설치 파일을 올리고, 앱은 새 버전이 있을 때만 사용자에게 알리는 방식이 적합합니다. 다운로드한 설치 파일은 SHA256과 Authenticode 서명을 확인한 뒤에만 실행하고, 업무 중에는 업데이트하지 않으며, 사용자가 승인한 뒤 앱을 종료하고 설치기를 실행해야 합니다. 현재 저장소에는 배포 서버 주소·서명 인증서·업데이트 정책이 정해져 있지 않아 이 부분은 구현하지 않았습니다.

필요한 정책은 HTTPS 고정 주소, 서명된 매니페스트, 다운그레이드 금지, 실행 중 로그인·암호 입력·제출 중 업데이트 연기, 실패 시 기존 파일 보존, 업데이트 확인 실패 시 업무 시작 계속입니다.
