# 나이스 로그인 도우미

**NEIS Login Helper** — 강원 업무포털 인증서 로그인과 나이스·K-에듀파인 실행을 돕는 Windows용 도구입니다.

버전 **0.4.12**. 기존 Microsoft Edge 프로필로 새 업무 창을 열고, 업무포털에 인증서 로그인한 뒤 공식 SSO 메뉴로 나이스·K-에듀파인을 엽니다.

> 교육부·교육청·나이스의 공식 프로그램이 아닌 **비공식 개인 프로젝트**입니다. 현재 지원 대상은 **강원 업무포털·Windows x64·한국어 Microsoft Edge**이며, 다른 교육청이나 브라우저에서의 동작은 보장하지 않습니다.

## 주요 기능

- 업무포털 인증서 로그인 후 나이스·K-에듀파인 중 선택한 시스템 열기
- 기존 Edge 프로필을 유지하면서 별도의 업무 창 사용
- 인증서 암호를 사용자 PC의 Windows 자격 증명 관리자에 저장
- 사용자가 직접 켜고 끌 수 있는 Windows 로그인 시 자동 시작
- 현재 사용자 로그온 예약 작업으로 자동 시작 켜기·끄기
- 자동 시작 후 바로 업무를 시작하거나 프로그램만 열어 직접 시작 선택
- `--auto`에서 메인 창 없이 작업 시작, 트레이 진행·중단·설정 제공, 성공하면 종료
- 입력 결과가 불확실하면 자동 재시도하지 않고 중단

이 저장소에는 **소스 코드와 문서만** 있습니다. 실행 파일이 필요하면 Windows에서 아래 빌드 절차를 진행하세요. 인증서, 개인 설정, 자격 증명, 실제 시험 로그 및 스크린샷은 포함하지 않습니다.

저장소 이름은 `neis-login`이며, 실행 파일명(`TeacherWorkStart.exe`)과 프로그램 내부 이름(강원 업무 시작 도우미)은 원본과 동일하게 유지합니다.

## 실행 환경

- Windows x64, .NET Framework 4.8
- 한국어 Microsoft Edge와 기존 정상 인증서·보안 프로그램
- 강원 업무포털 사용 환경

Python, Node.js, Playwright 설치는 필요하지 않습니다. Chrome·다른 교육청·다른 PC에서는 검증하지 않았습니다.

## 빌드

Windows PowerShell 또는 PowerShell에서 저장소 루트를 작업 폴더로 지정하고 실행합니다.

```powershell
.\build.ps1
```

Windows의 .NET Framework64 C# 컴파일러와 UI Automation/WPF 라이브러리를 사용합니다. 빌드는 프로그램을 실행하거나 자동 시작을 등록하지 않습니다.

생성 파일:

- TeacherWorkStart.exe: 일반 사용자용 GUI
- TeacherWorkStart.Cli.exe: 개발·진단용 CLI
- 각각의 .exe.config: .NET 런타임 설정

생성된 EXE와 해당 .exe.config는 같은 폴더에 둡니다. 기본 사용 방법은 [사용안내.md](사용안내.md)를 참고하세요. 소스에 포함된 TeacherWorkStart.exe.config는 .NET 런타임 선언이며 개인 설정 파일이 아닙니다.

## 회귀 테스트

```powershell
.\test.ps1
```

Windows에서 GUI·CLI 빌드와 189개 회귀 검사를 통과했습니다. 0.4.12는 인증서 버튼의 동일 문서·활성·표시 상태 안정화만 5초에서 2초로 줄였습니다. 실제 사용자 환경에서 새 설치본의 인증 시작 1회·로그인·두 시스템 초기 화면을 확인했고 준비 대기는 2.70초였습니다. 로그온 예약 작업의 PT10S와 XML은 유지됐습니다. 회귀 테스트는 실제 인증서 암호·사용자 설정·시작 등록을 변경하지 않습니다. Windows 재로그온 직후의 반복 성공률과 흰 화면 원인은 아직 검증하지 않았습니다.

회귀 테스트는 실제 인증서 암호·브라우저 로그인·사용자 설정·Startup 항목을 변경하지 않습니다. 핫키 충돌 시험에서는 Ctrl+Alt+F10을 잠시 등록했다가 해제합니다. 별도로 실제 사용자 환경에서 예약 작업 등록·Startup 백업·복원·재전환을 확인했습니다. 실제 로그온 트리거 실행과 속도 개선, 인증서 로그인, 다른 PC·보안제품 반응은 0.4.5에서 시험하지 않았습니다. 상세 범위는 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

## 동작과 제한

- 기존 Edge 프로필의 새 업무 창을 사용합니다. 나이스·K-에듀파인은 주소 직접 이동을 사용하지 않고 업무포털의 공식 메뉴를 누릅니다.
- 암호는 각 사용자가 로컬 마스킹 창에 직접 등록합니다. Windows 자격 증명 관리자에서 로컬 프로세스로만 불러오며 명령행·로그·클립보드에 넣지 않습니다.
- 창과 인증서·입력 요소를 확인하고 1회 제출합니다. 실패 시 자동 재제출이나 다른 입력 방식으로 자동 전환하지 않습니다.
- 인증서창이 아직 없으면 같은 로그인 문서와 표시·활성 버튼이 2초 동안 안정된 뒤 한 번 실행합니다. 이 준비 대기는 최대 60초, 실행 후 실제 인증서 목록 준비 대기는 최대 60초입니다. 이미 열린 인증서창은 다시 누르지 않습니다. 공개 인증 코드는 초기화 전 로그인 요청을 그대로 반환할 수 있으나 완료 상태를 DOM에 공개하지 않습니다. 이 2초는 UI 안정화 관찰이며 보안모듈 초기화 완료를 증명하는 신호는 아닙니다. 모듈 상태·콜백을 변경하지 않습니다.
- 인증서창 준비 중 예상한 포털 문서를 확인하지 못하거나 UIA 문서가 교체되면 값 없이 이벤트만 기록합니다. 이 이벤트만으로 흰 화면·실제 새로고침을 확정하지 않습니다.
- 인증서 버튼 실행 전에, 선택된 업무 탭과 HTTPS 로그인 문서·주소가 일치하고 화면에 표시된 텍스트·버튼·링크·입력칸이 없는 상태가 10초 지속되면 UIA 새로고침을 1회 허용합니다. 표시된 인증서창·암호칸·다른 창형 대화상자·미확인 입력·중단 요청이 있으면 수행하지 않습니다. 직접 실행 기능이 없으면 키보드·좌표로 대체하지 않습니다. 실행 결과가 미확인이면 반복하지 않습니다. 이미 로그인된 메인 화면과 인증서 입력/제출 이후에는 적용하지 않습니다.
- 공식 SSO 메뉴는 새 포털 문서·로그아웃 표식·링크가 준비되기를 최대 30초 기다린 뒤 한 번 실행합니다. 다른 Edge 창의 탭을 순회하던 준비 검사는 해당 업무 창으로 한정했습니다. 수동 실행의 오류 유형/HRESULT도 실행 로그에 남깁니다.
- 중단이 제출 시작보다 먼저 수락되면 확인 버튼을 실행하지 않습니다. 이미 시작한 제출은 취소됐다고 표시하지 않습니다.
- 중단 단축키는 Ctrl+Alt+F10입니다. 등록 실패 시 화면에 알리며 중단 버튼은 사용할 수 있습니다.
- 입력·제출 및 일부 창·탭 동작에서 전면 전환이 발생할 수 있습니다. 완전 백그라운드 동작을 보장하지 않습니다.
- 자동 시작은 사용자의 명시적 버튼 또는 등록 CLI 실행으로만 변경합니다. 업데이트·일반 실행·인증서 등록으로 자동 전환하지 않습니다.
- `--auto`는 설정 완료·인증서 유효기간·저장 암호 존재·미확인 시도를 먼저 검사합니다. 준비가 됐으면 메인 창 없이 실행하고, 성공하면 트레이도 정리해 종료합니다. 설정 미완료·오류·중단이면 안내 창을 표시하며 자동 재시도하지 않습니다.
- 트레이의 **설정 열기**는 진행 중 작업에 중단을 요청하고 작업 정리 후 같은 프로세스의 설정 창을 엽니다. 이미 시작한 제출은 되돌리지 않습니다. 조용한 실행은 도우미 창에 관한 것으로 Edge의 전면 전환은 발생할 수 있습니다.
- `TIMING_HELPER_START`, `TIMING_EDGE_READY`, `TIMING_CERTIFICATE_READY`, `TIMING_LOGIN_COMPLETE`는 실행 시각과 도우미 컨텍스트 생성 이후 경과 밀리초만 기록합니다. 기존 로그인 세션이면 인증서 준비 단계가 없고, 도달하지 않은 단계는 기록하지 않습니다. Windows 로그온 시각이나 전체 SSO 완료 시간은 아닙니다.
- **자동 시작 켜기**는 현재 사용자 로그온 트리거에 **10초 지연**으로 설치된 `TeacherWorkStart.exe --auto`를 등록합니다. InteractiveToken·LeastPrivilege로 현재 사용자 화면에서 실행하며 Windows 암호는 저장하지 않습니다. IgnoreNew와 기존 프로그램 잠금으로 중복 실행을 막고 실패 시 스케줄러 재시도도 등록하지 않습니다. 수동 실행·업무 시작 버튼에는 지연을 넣지 않습니다. 이전 즉시 실행 등록은 **10초 지연 적용** 버튼으로 같은 작업의 지연만 변경합니다. 다른 사용자/대상/권한 또는 사용자 지정 지연은 덮어쓰지 않습니다.
- 로그온 후 동작은 **바로 로그인·업무 시작 / 프로그램만 열기**에서 선택합니다. 후자는 자격 증명 사전 검사와 브라우저 작업을 시작하지 않고 창·트레이에서 수동 시작을 기다립니다. 선택은 즉시 저장되며 예약 작업 인수는 바뀌지 않습니다. 기존 설정 파일은 자동 업무 시작 동작을 유지합니다.
- 기존 Startup 방식의 사용자 선택·복원 버튼과 CLI 복원 기능은 제거했습니다. 예전 등록이 있으면 원본을 `startup-backup`에 보관하고 활성 위치에서 정리합니다. 백업 복구 코드는 전환 실패 시 원래 상태를 보존하기 위한 내부 경로만 유지합니다. **자동 시작 끄기**는 활성 등록을 정리하되 백업·인증서·암호를 보존합니다.
- 자동 실행은 사전 검사 전부터 시계 옆에 책 모양 아이콘을 만듭니다. 왼쪽/오른쪽 클릭으로 진행 상태·중단·설정을 확인하며 일반 창에도 트레이를 제공합니다. 아이콘 위치와 숨김(^)은 Windows가 관리하므로 강제로 고정하지 않습니다. 자동 작업 성공 시는 종료하고, 프로그램만 열기/일반 실행에서는 창을 닫기 전까지 유지합니다.
- 등록이 거부되거나 전환에 실패하면 기존 Startup 상태를 유지·복원합니다. 권한 상승·다른 이름으로 차단 회피·보안설정 변경은 하지 않습니다. 같은 이름의 다른 작업이나 다른 대상의 링크는 덮어쓰거나 삭제하지 않습니다.
- Windows 재로그온 시험과 다른 PC의 검증은 별도입니다. 과거 V3 차단 이력이 있으므로 이 소스나 로컬 시험 성공을 모든 환경의 허용 판정으로 간주하지 않습니다. 보안프로그램 해제·예외 추가·보안모듈 우회는 하지 않습니다.

## 개인 데이터 제외

실행 추적은 `%LOCALAPPDATA%\TeacherWorkStart\logs\startup-*.jsonl`에 실행별로 저장합니다. 시각·버전·실행 모드·실행 ID·프로세스/세션 번호·단계·경과 시간·기존 대기 한도·오류 유형/HRESULT를 기록합니다. 0.4.10부터 전환 전후 창 핸들·프로세스 번호, API 반환값·실제 활성 여부·최소화 여부, 원래 창 복귀/생략 사유, 대기 중 문서·로그아웃 표식의 불리언 상태를 추가합니다. 인증 전 빈 화면 복구에서 이미 조사한 문서·빈 화면·인증 UI·새로고침 지원 여부도 상태 변화 때만 불리언으로 기록합니다. API 직후 표본과 대기 중 상태 변화 관찰이며 모든 순간의 포커스 이동을 추적하는 Windows 이벤트 후크는 아닙니다. 명령행 원문·URL·화면 텍스트·설정·인증서·암호·예외 메시지는 넣지 않습니다. `--logging-self-check`는 설정·자격 증명·브라우저를 사용하지 않고 로그 생성만 확인합니다. PROCESS_EXIT는 프로세스 종료이며 로그인 성공 표식이 아닙니다. 0.4.6은 로깅만 추가했고 기존 대기 한도·인증 동작·예약 작업을 변경하지 않습니다.

실행 시 생성되는 설정·상태·로그 및 인증서 관련 개인 데이터는 저장소에 올리지 마세요. 특히 사용자 앱 데이터 폴더, 인증서 파일, Windows 자격 증명 내보내기는 이 프로젝트 소스가 아닙니다. 각 사용자가 자신의 PC에서 처음 설정을 진행해야 합니다.
