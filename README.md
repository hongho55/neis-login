# 강원 업무 시작 도우미

버전 **0.4.2**. Windows의 기존 Microsoft Edge 프로필을 사용해 새 업무 창에서 업무포털 인증서 로그인 후 나이스·K-에듀파인을 공식 SSO 메뉴로 엽니다.

이 저장소 묶음에는 빌드에 필요한 소스와 문서만 있습니다. 실행 파일, 인증서, 개인 설정, 자격 증명, 실제 시험 로그 및 스크린샷은 포함하지 않습니다. GitHub 업로드는 이 폴더의 **내용 전체**를 저장소 루트에 넣으면 됩니다. .gitignore도 포함하세요.

## 실행 환경

- Windows x64, .NET Framework 4.8
- 한국어 Microsoft Edge와 기존 정상 인증서·보안 프로그램
- 강원 업무포털 사용 환경

Python, Node.js, Playwright 설치는 필요하지 않습니다. Chrome·다른 교육청·다른 PC에서는 검증하지 않았습니다.

## 빌드

Windows PowerShell 또는 PowerShell에서 저장소 루트를 작업 폴더로 지정하고 실행합니다.

```powershell
.\build.ps1
```

Windows의 .NET Framework64 C# 컴파일러와 UI Automation/WPF 라이브러리를 사용합니다. 빌드는 프로그램을 실행하거나 자동 시작을 등록하지 않습니다.

생성 파일:

- TeacherWorkStart.exe: 일반 사용자용 GUI
- TeacherWorkStart.Cli.exe: 개발·진단용 CLI
- 각각의 .exe.config: .NET 런타임 설정

생성된 EXE와 해당 .exe.config는 같은 폴더에 둡니다. 기본 사용 방법은 [사용안내.md](사용안내.md)를 참고하세요. 소스에 포함된 TeacherWorkStart.exe.config는 .NET 런타임 선언이며 개인 설정 파일이 아닙니다.

## 소스 구성

| 파일 | 역할 |
|---|---|
| src/Program.cs | 설정, GUI, 로컬 마스킹 암호 등록, 실행 진입점 |
| src/Portal.cs | 전용 Edge 창 추적, 인증서·URL 검증, 로그인 및 공식 시스템 메뉴 |
| src/Native.cs | Windows API, UIA 보조 기능, Windows 자격 증명 관리자 처리 |
| src/StartupRegistration.cs | 사용자 버튼으로 Startup 바로가기 등록·삭제 |
| src/WindowFlow.cs | 새 업무 창 선택과 원래 작업 창 복귀 정책 |
| src/PortalTabPolicy.cs | 탭 제목 변경·표시 지연에 대응하는 포털 탭 식별 |
| src/Version.cs | 버전 메타데이터 |
| src/StrictSession.cs | 기존 CLI 진단 명령 구현 |
| src/FocusAudit.cs | CLI 진단에서 사용하는 전면 창 이벤트 관찰 |

마지막 두 파일도 현재 Program.cs가 참조하므로 재현 가능한 빌드를 위해 포함했습니다. 일반 GUI 실행과 임시 실험 스크립트는 구분되며, 작업 폴더의 일회성 시험 코드는 포함하지 않았습니다.

## 동작과 제한

- 기존 Edge 프로필의 새 업무 창을 사용합니다. 나이스·K-에듀파인은 주소 직접 이동을 사용하지 않고 업무포털의 공식 메뉴를 누릅니다.
- 암호는 각 사용자가 로컬 마스킹 창에 직접 등록합니다. Windows 자격 증명 관리자에서 로컬 프로세스로만 불러오며 명령행·로그·클립보드에 넣지 않습니다.
- 창과 인증서·입력 요소를 확인하고 1회 제출합니다. 실패 시 자동 재제출이나 다른 입력 방식으로 자동 전환하지 않습니다.
- 입력·제출 및 일부 창·탭 동작에서 전면 전환이 발생할 수 있습니다. 완전 백그라운드 동작을 보장하지 않습니다.
- 자동 시작은 사용자가 해당 버튼을 누를 때만 등록합니다. 이미 정상 등록된 시작 항목은 업데이트를 위해 재등록할 필요가 없습니다.
- Windows 재로그온 시험과 다른 PC의 검증은 별도입니다. 과거 V3 차단 이력이 있으므로 이 소스나 로컬 시험 성공을 모든 환경의 허용 판정으로 간주하지 않습니다. 보안프로그램 해제·예외 추가·보안모듈 우회는 하지 않습니다.

## 개인 데이터 제외

실행 시 생성되는 설정·상태·로그 및 인증서 관련 개인 데이터는 저장소에 올리지 마세요. 특히 사용자 앱 데이터 폴더, 인증서 파일, Windows 자격 증명 내보내기는 이 프로젝트 소스가 아닙니다. 각 사용자가 자신의 PC에서 처음 설정을 진행해야 합니다.
