# C# 설치 시제품

0.4.12 성공 EXE와 설정 파일을 내장한 설치 흐름의 시제품입니다. 배포가 검증된 최종 설치기가 아닙니다.

- `build-installer.ps1`: 기존 도우미 EXE를 변경하지 않고 시제품 설치 EXE를 빌드합니다.
- `test-installer.ps1`: 임시 환경과 테스트 자식 프로세스로 23개 설치 검사를 실행합니다. 실제 사용자 자격 증명·인증서·자동 시작은 변경하지 않습니다.
- 실제 사용자 UI 시험은 Esc로 중단됐으며 실제 설치 완료를 확인하지 않았습니다.

현재 소수 배포 권고는 검증된 **Inno Setup** 재사용입니다. StartupTask가 필수라면 **Store MSIX** 경로를 별도로 검토합니다. 판단 근거는 [배포 방식 비교](../docs/배포방식-비교.md)를 참고하세요.

이 시제품을 그대로 공개 배포하거나 MSIX 설치 파일로 안내하지 않습니다.
